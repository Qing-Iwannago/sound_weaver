# 音的基础知识
音是由物体振动产生的。音乐中使用的音称为乐音，具有固定的音高。噪音没有固定音高。
音的四种性质：音高（由振动频率决定）、音值（音的长短）、音量（音的强弱）、音色（音的色彩）。
音高由振动频率决定，频率越高音越高，频率越低音越低。
国际标准音：A4=440Hz，即中央C上方的A音每秒振动440次。

# 乐音体系与音级
乐音体系是音乐中使用的所有乐音的总和。
基本音级有7个：C D E F G A B，对应唱名Do Re Mi Fa Sol La Si。
变化音级：在基本音级前加升号(#)或降号(b)，如#C、bE。
等音：音高相同但名称不同的音，如#C和bD是等音。
音列：将乐音体系中所有音按高低顺序排列。
音域：音列的总范围，从最低音到最高音。

# 音的分组
为区分音高相同但音区不同的音，将音分组。
国际通用分组方法：大字组、小字组、小字一组（中央C所在组）、小字二组等。
中央C是小字一组的C音，钢琴上位于中间位置，MIDI编号为60。

# 音律
十二平均律：将一个八度分成12个完全相等的半音，是现代音乐最常用的律制。
五度相生律：以纯五度为基础生成各音，音程纯正但不同调转换有问题。
纯律：以自然泛音列为基础，音程最纯正，适合合唱。
半音：相邻两个音之间最小的音程单位。
全音：由两个半音组成。

# 记谱法基础
五线谱：由五条横线组成，从下到上依次为第一线到第五线。
加线：五线谱不够用时在上方或下方加的短线。
间：两条线之间的空间，从下到上依次为第一间到第四间。
谱号：写在五线谱开头，确定音高位置。
高音谱号（G谱号）：第二线为G音（Sol），适合高音乐器。
低音谱号（F谱号）：第四线为F音（Fa），适合低音乐器。
中音谱号（C谱号）：中间线为中央C，适合中音乐器如中提琴。

# 音符与时值
全音符：空心椭圆，时值最长，通常为4拍。
二分音符：空心椭圆加符干，时值为全音符的一半，2拍。
四分音符：实心椭圆加符干，时值为全音符的四分之一，1拍。
八分音符：实心椭圆加符干加一条符尾，时值半拍。
十六分音符：实心椭圆加符干加两条符尾，时值四分之一拍。
附点音符：音符右边加一个点，时值增加原来的一半。
二连音、三连音：将时值平均分成非常规数量的音符。

# 休止符
全休止符：黑色长方块挂在第四线下，休止4拍。
二分休止符：黑色长方块放在第三线上，休止2拍。
四分休止符：休止1拍。
八分休止符：休止半拍。
十六分休止符：休止四分之一拍。

# 节拍与节奏
节拍：音乐中强弱拍规律性交替。
拍子：节拍的单位，用分数表示，分子为每小节拍数，分母为拍的音符种类。
2/4拍：每小节2拍，以四分音符为一拍，强弱规律为强弱。
3/4拍：每小节3拍，强弱弱，常见于华尔兹。
4/4拍：每小节4拍，强弱次强弱，最常见的拍子。
6/8拍：每小节6个八分音符，强弱弱次强弱弱，有摇荡感。
切分节奏：弱拍或弱位上的音延续到强拍，造成重音移位效果。
附点节奏：附点音符后接短音符，造成长短不均的律动感。

# 速度标记
Largo（广板）：极慢，庄严，BPM 40-60。
Grave（庄板）：缓慢庄重，BPM 40-50。
Lento（慢板）：缓慢，BPM 52-68。
Adagio（慢板）：从容不迫，BPM 56-76。
Andante（行板）：步行速度，BPM 72-88。
Moderato（中板）：适中速度，BPM 88-112。
Allegretto（小快板）：较快，BPM 100-120。
Allegro（快板）：快速活泼，BPM 112-152。
Vivace（活泼的）：生动活泼，BPM 132-168。
Presto（急板）：极快，BPM 160-200。
Accelerando（渐快）：逐渐加快速度。
Ritardando/Rallentando（渐慢）：逐渐减慢速度。

# BPM与情绪对应
BPM 40-60：极慢，适合葬礼进行曲、极度悲伤的歌曲、冥想音乐。
BPM 60-72：慢速，适合摇篮曲、安眠曲、极度忧郁的情歌。
BPM 72-88：中慢速，适合抒情情歌、忧郁民谣、感伤歌曲。
BPM 88-100：中速偏慢，适合普通情歌、抒情流行、温柔歌曲。
BPM 100-116：中速，适合一般流行歌曲、轻快民谣。
BPM 116-132：中快速，适合欢快流行、轻摇滚、舞曲。
BPM 132-148：快速，适合劲爆舞曲、激情摇滚、电子音乐。
BPM 148-168：很快，适合快节奏电子、朋克、金属音乐。
BPM 168以上：极快，适合速度金属、激烈电子音乐。

# 力度标记
ppp（极弱）：力度极轻。
pp（很弱）：力度很轻。
p（弱）：力度轻柔。
mp（中弱）：力度略轻。
mf（中强）：力度略强。
f（强）：力度强。
ff（很强）：力度很强。
fff（极强）：力度极强。
crescendo（渐强）：逐渐增强。
decrescendo/diminuendo（渐弱）：逐渐减弱。
sforzando（sf/sfz）：突然强调某个音。

# 音程
音程：两个音之间的距离。
度数：音程的基本单位，从低音到高音数经过的音级数。
一度（同度）：两个相同的音，距离为0。
二度：相邻两个音级，小二度=1个半音，大二度=2个半音。
三度：小三度=3个半音，大三度=4个半音。
四度：纯四度=5个半音，增四度=6个半音（三全音）。
五度：减五度=6个半音，纯五度=7个半音。
六度：小六度=8个半音，大六度=9个半音。
七度：小七度=10个半音，大七度=11个半音。
八度（纯八度）：12个半音，音高相差一倍。
协和音程：听感和谐，包括纯一度、纯四度、纯五度、纯八度（完全协和）和大小三度、大小六度（不完全协和）。
不协和音程：听感紧张，包括大小二度、大小七度、增四度、减五度。

# 大调音阶
大调音阶由7个音组成，音程结构为：全全半全全全半（W W H W W W H）。
大调特点：明亮、开朗、积极、有力量感。
C大调：C D E F G A B，无升降号，最基础的调式。
G大调：G A B C D E #F，1个升号，温暖明亮，常用于民谣和流行。
D大调：D E #F G A B #C，2个升号，雄壮有力，常用于进行曲。
A大调：A B #C D E #F #G，3个升号，明亮热情，常用于欢快歌曲。
E��调：E #F #G A B #C #D，4个升号，华丽辉煌。
B大调：B #C #D E #F #G #A，5个升号，光辉灿烂。
F大调：F G A bB C D E，1个降号，柔和温暖，常用于抒情歌曲。
bB大调：bB C D bE F G A，2个降号，丰厚圆润。
bE大调：bE F G bA bB C D，3个降号，庄重深沉。
bA大调：bA bB C bD bE F G，4个降号，柔美梦幻。

# 小调音阶
自然小调音程结构：全半全全半全全（W H W W H W W）。
小调特点：忧郁、深沉、内敛、情感复杂。
和声小调：自然小调第7音升高半音，增加导音的倾向性。
旋律小调：上行时第6、7音升高，下行时还原，旋律更流畅。
A小调：A B C D E F G，无升降号，C大调的关系小调，最常用的小调。
E��调：E #F G A B C D，1个升号，G大调的关系小调，悲伤内敛。
B小调：B #C D E #F G A，2个升号，深沉忧郁。
D小调：D E F G A bB C，1个降号，庄重深沉，常用于悲剧性音乐。
G小调：G A bB C D bE F，2个降号，忧郁激情。
C小调：C D bE F G bA bB，3个降号，悲壮激情，贝多芬最爱用的调式。

# 五声调式
五声调式：由5个音组成的调式，是中国传统音乐的基础。
宫调式：以宫音为主音，相当于西方大调，明亮开朗。
商调式：以商音为主音，高亢有力，略带忧郁。
角调式：以角音为主音，清新柔和，略带忧郁。
徵调式：以徵音为主音，明朗欢快，活泼向上。
羽调式：以羽音为主音，相当于西方小调，哀婉忧郁。
五声音阶在中国民歌、戏曲、古典音乐中广泛使用。

# 和弦基础
和弦：三个或三个以上不同音高的音同时发声。
三和弦：由三个音组成，根音、三音、五音。
大三和弦：根音+大三度+纯五度，音响明亮，如C和弦（C E G）。
小三和弦：根音+小三度+纯五度，音响柔和忧郁，如Am和弦（A C E）。
增三和弦：根音+大三度+增五度，音响紧张不稳定。
减三和弦：根音+小三度+减五度，音响阴暗压抑。
七和弦：三和弦加上七度音，共4个音。
大七和弦：大三和弦+大七度，如Cmaj7（C E G B），爵士常用，温暖华丽。
属七和弦：大三和弦+小七度，如G7（G B D F），有强烈的解决倾向。
小七和弦：小三和弦+小七度，如Am7（A C E G），柔和忧郁，流行常用。
半减七和弦：减三和弦+小七度，阴暗忧郁，爵士常用。

# 和弦进行
I-IV-V-I：最基本的和弦进行，稳定感强，传统音乐骨架。
I-V-vi-IV（C-G-Am-F）：现代流行音乐最常用进行，明亮温暖，无数经典歌曲使用。
vi-IV-I-V（Am-F-C-G）：忧郁中带希望，适合抒情流行和情歌。
I-IV-vi-V（C-F-Am-G）：温暖感人，适合慢歌和情歌。
ii-V-I：爵士乐最核心进行，Dm-G-C，有强烈的解决感。
I-vi-IV-V（C-Am-F-G）：50年代流行，怀旧感强，用于老式情歌。
vi-III-IV-I（Am-Em-F-C）：略带神秘感，适合带有忧郁色彩的流行。
I-III-IV-iv（C-Em-F-Fm）：有借用和弦，情绪丰富，适合戏剧性歌曲。
I-bVII-IV（C-Bb-F）：摇滚常用，有力量感。
i-bVI-bIII-bVII（Am-F-C-G）：自然小调进行，忧郁深沉。
i-iv-V-i（Am-Dm-E-Am）：古典小调进行，悲剧感强。
II-V-I（爵士）：Dm7-G7-Cmaj7，爵士标准进行，复杂华丽。

# 转位和弦
和弦转位：将和弦的根音以外的音放到最低音位置。
第一转位：三音在最低音，记为6和弦，如C/E。
第二转位：五音在最低音，记为64和弦，如C/G。
转位和弦使低音线条更流畅，增加音乐的层次感。

# 终止式
完全终止：V-I，最有结束感的终止，用于乐句或乐曲结尾。
不完全终止：I-V，有悬挂感，用于乐句中间。
变格终止：IV-I，阿门终止，宗教音乐常用，平静祥和。
假终止：V-vi，本应解决到I却转到vi，出乎意料，增加戏剧性。

# 流行音乐特征
流行音乐：结构简单，副歌朗朗上口，BPM通常在100-130。
常用和弦进行：C-G-Am-F 或 Am-F-C-G。
歌曲结构通常为：主歌A-预副歌B-副歌C-主歌A-副歌C-桥段D-副歌C。
常用乐器：钢琴、吉他、贝斯、鼓组、弦乐、合成器。
流行情歌常用A小调或C大调，BPM在80-110之间。
欢快流行常用C大调或G大调，BPM在120-135之间。

# 爵士乐特征
爵士乐：起源于美国黑人音乐，融合蓝调和拉格泰姆。
和弦复杂，大量使用七和弦、九和弦、十一和弦、十三和弦。
标准进行：ii-V-I，如Dm7-G7-Cmaj7。
即兴演奏是爵士乐的核心特征。
常用调式：大调、多利亚调式、混合利底亚调式。
常用乐器：萨克斯、小号、长号、钢琴、贝斯、爵士鼓。
BPM范围广泛，从慢速爵士（60-80）到快速Bebop（200以上）。
布鲁斯音阶：在自然小调基础上加降五度（蓝调音），具有独特的忧郁色彩。

# 古典音乐特征
古典音乐：结构严谨，旋律优美，动态变化丰富。
常见曲式：奏鸣曲式（呈示部-发展部-再现部）、变奏曲、回旋曲、赋格。
常用乐器：钢琴、弦乐四重奏（两把小提琴、中提琴、大提琴）、管弦乐队。
调性关系：关系大小调、平行大小调、属调、下属调。
巴洛克时期（1600-1750）：巴赫、亨德尔，复调音乐，对位法。
古典时期（1750-1820）：海顿、莫扎特、贝多芬，主调音乐，奏鸣曲式。
浪漫时期（1820-1900）：肖邦、李斯特、柴可夫斯基，情感丰富，技巧复杂。

# 摇滚音乐特征
摇滚：节奏强劲，电吉他为主，BPM通常在120-160。
常用和弦：电吉他强力和弦（只有根音和五音），如E5、A5、G5。
常用调式：自然小调、五声音阶、蓝调音阶。
歌曲结构：主歌-副歌-间奏（吉他Solo）-副歌。
子流派：硬摇滚（Hard Rock）、重金属（Heavy Metal）、朋克（Punk）、另类摇滚（Alternative）。
重金属：BPM更快（140-200），音色更重，主题更黑暗。
朋克：BPM极快（160-220），和弦简单，情绪激烈。

# 民谣特征
民谣：原声吉他为主，歌词故事性强，情感真挚。
BPM通常在70-110之间，偏向中慢速。
常用调式：C大调、G大调、D大调。
常用和弦：G-C-D-Em 或 C-G-Am-F。
歌曲结构：较自由，常有长段主歌。
常用技巧：分解和弦（Fingerpicking）、扫弦（Strumming）。
中国民谣：常用五声音阶，歌词描写自然、乡愁、爱情。

# 电子音乐特征
电子音乐：合成器为主，节拍由鼓机产生，节奏规律机械。
BPM通常在120-150之间（舞曲类型）。
House音乐：BPM 120-130，4/4拍，强调每拍的底鼓。
Techno：BPM 130-150，机械感强，重复性强。
Trance：BPM 128-145，旋律感强，有情绪起伏。
Dubstep：BPM 138-142（半拍约70），强调低音炮效果。
Lo-fi：BPM 70-90，音质有意做旧，轻松慵懒，适合学习。

# R&B特征
R&B（节奏蓝调）：融合了蓝调、爵士、流行元素。
律动感强，常用切分节奏和后置重音。
BPM通常在70-100之间。
常用和弦：借用爵士的七和弦、九和弦。
歌词主题：爱情、欲望、情感纠葛。
常用乐器：电钢琴、电贝斯、合成器、打击乐。
代表人物：迈克尔·杰克逊、玛丽亚·凯莉、碧昂斯。

# 嘻哈音乐特征
嘻哈：起源于美国黑人社区，说唱（Rap）为核心。
BPM通常在85-100之间（Trap类型可到140以上）。
节拍：强调第2和第4拍（弱拍），与摇滚相反。
采样（Sampling）：截取其他歌曲片段重新使用。
Trap：808鼓机、滚动的快速踩镲、沉重低音。
常用音阶：小调五声音阶、蓝调音阶。

# 情绪与音乐参数对应
欢快喜悦：大调（C、G、D大调），BPM 120-140，力度强（f-ff），音符密集，跳跃感强。
忧郁悲伤：小调（A、D、G小调），BPM 60-80，力度轻（p-mp），音符稀疏，旋律下行。
激动兴奋：大调或小调，BPM 140以上，力度很强（ff-fff），节奏快速密集。
平静安宁：大调（C、F大调），BPM 70-90，力度中等（mp-mf），旋律流畅平稳。
浪漫温柔：大调（F、bB大调），BPM 80-100，力度中等，旋律优美起伏。
悲壮激情：小调（C、D小调），BPM 90-120，力度强，旋律戏剧性强。
神秘深邃：小调或特殊调式（如弗里几亚调式），BPM 80-110，力度变化大。
思念乡愁：五声调式（羽调式），BPM 70-90，力度中等，旋律带有民族色彩。
轻松惬意：大调（C、G大调），BPM 100-120，力度中等，节奏轻快但不急促。

# 旋律写作技巧
旋律线条：上行旋律给人积极向上感，下行旋律给人下沉忧郁感。
旋律高潮：通常在副歌部分达到音域最高点，情绪最强烈处。
重复与变化：核心动机重复建立记忆点，适当变化避免单调。
问答句式：前句（问）在属音结束，后句（答）在主音结束。
跳进与级进：级进（相邻音移动）平稳流畅，跳进（跨越多个音）有张力。
旋律节奏：与歌词重音对应，长音通常在重要歌词上。

# 歌词写作与音乐配合
歌词韵脚：尾韵使歌词朗朗上口，常用AABB、ABAB、ABBA等格式。
语气与旋律：疑问句通常旋律上扬，陈述句通常平稳或下行。
押韵位置：通常在小节的第4拍或第2拍（弱拍末）。
歌词意象：具体意象比抽象概念更能打动听众。
主歌（Verse）：讲述故事背景，情绪相对平缓。
预副歌（Pre-chorus）：情绪逐渐积累，为副歌做铺垫。
副歌（Chorus）：情绪最强烈，最易记的旋律和歌词在此。
桥段（Bridge）：提供对比和新鲜感，通常只出现一次。

# 编曲技巧
层次感：从低频到高频依次安排乐器，底鼓-贝斯-吉他/钢琴-人声-弦乐。
动态对比：主歌编曲简单，副歌加入更多乐器，形成对比。
前奏：通常引用副歌旋律，让听众快速进入状态。
间奏：通常为乐器Solo或和弦进行的变奏。
尾奏：可以渐弱消失（Fade out）或明确结束（Full stop）。
和声：人声和声通常用三度或六度叠加，增加丰厚感。

# MIDI与数字音乐
MIDI：乐器数字接口，记录音符信息而非声音本身。
音符编号：中央C=60，每升高一个半音加1，每降低一个半音减1。
音符60=C4（中央C），61=#C4，62=D4，以此类推。
力度（Velocity）：0-127，0为无声，127为最强，通常演奏在60-100之间。
Program Change：切换乐器音色，0=钢琴，24=吉他，40=小提琴，73=长笛。
通道（Channel）：MIDI有16个通道，通道10固定为打击乐。
PPQ（每四分音符脉冲数）：决定时间分辨率，通常为48或96。
Tempo（速度）：以微秒/四分音符表示，60BPM=1000000微秒。

# 常见乐器音域与特点
钢琴：音域最广（A0-C8），表现力丰富，适合各种风格。
小提琴：G3-A7，声音明亮穿透，适合旋律线条。
大提琴：C2-C6，声音浑厚温暖，适合低音旋律和伴奏。
吉他：E2-E5（标准调弦），音色温暖，流行民谣摇滚通用。
贝斯：E1-G4，提供低频支撑，与鼓组共同构成节奏基础。
萨克斯：根据种类不同，音色介于木管和铜管之间，爵士必备。
小号：E3-C6，声音明亮嘹亮，适合旋律和华彩段落。
长笛：C4-D7，声音清澈空灵，适合高音旋律。

# 音乐结构与曲式
二部曲式（AB）：由对比的两个部分组成，简单但有对比。
三部曲式（ABA）：再现部分增加统一感，奏鸣曲慢乐章常用。
回旋曲式（ABACADA）：主题A反复出现，插入不同对比段落。
变奏曲式：主题呈示后进行多次变奏，保持统一又有变化。
奏鸣曲式：呈示部（主题1+主题2）-发展部-再现部，古典音乐最重要曲式。
流行歌曲结构：Intro-Verse-Pre-chorus-Chorus-Verse-Chorus-Bridge-Chorus-Outro。

# 调式情绪详细说明
C大调：最纯粹的明亮感，无任何升降号，给人清新、纯洁、开朗的感觉，适合儿歌、欢快流行。
G大调：温暖而明亮，带有田园气息，适合乡村音乐、民谣、温馨的歌曲。
D大调：雄壮有力，光辉灿烂，适合进行曲、颂歌、激昂的歌曲。
A大调：热情明亮，充满活力，适合欢快的流行、舞曲。
E��调：华丽辉煌，有贵族气质，适合宏大的古典作品。
F大调：柔和温暖，带有温柔感，适合浪漫情歌、抒情作品。
bB大调：丰厚圆润，适合管乐和弦乐作品，温暖感强。
bE大调：庄重深沉，有英雄气概，贝多芬《英雄交响曲》用此调。
A小调：最常用的小调，忧郁但不过分，温柔的悲伤，适合大多数抒情歌曲。
E��调：深沉内敛，有孤独感，适合深情的慢歌。
D小调：庄重悲壮，莫扎特《安魂曲》用此调，适合宏大的悲剧作品。
C小调：激情与忧郁并存，贝多芬最爱，适合戏剧性强的作品。
G小调：热情而忧郁，有东欧民族音乐色彩。
B小调：深沉忧郁，有神秘感，肖邦多首夜曲用此调。


# 调性功能
主功能（Tonic）：代表稳定、归属、结束感，主要和弦为 I、vi、iii。
下属功能（Subdominant）：具有离开主和弦、推动发展的作用，主要和弦为 IV、ii。
属功能（Dominant）：具有最强的不稳定感和回归主和弦的倾向，主要和弦为 V、vii°。
典型功能进行：T-S-D-T，即主功能→下属功能→属功能→主功能。
C大调中：C为主功能，F和Dm为下属功能，G和Bdim为属功能。
功能和声能够帮助判断一个和弦进行是否具有自然的方向感。

# 级数和弦
大调自然音阶上的七个三和弦依次为：
I 大三和弦
ii 小三和弦
iii 小三和弦
IV 大三和弦
V 大三和弦
vi 小三和弦
vii° 减三和弦

C大调对应：
C - Dm - Em - F - G - Am - Bdim。

自然小调中的七个和弦通常为：
i 小三和弦
ii° 减三和弦
III 大三和弦
iv 小三和弦
v 小三和弦
VI 大三和弦
VII 大三和弦。

A小调对应：
Am - Bdim - C - Dm - Em - F - G。

# 和声小调中的属和弦
自然小调中的V级通常是小和弦，回到主和弦的推动力较弱。
实际创作中经常升高第7级，形成和声小调。
例如A小调中将G升为G#，V级由Em变成E或E7。
E7→Am具有很强的属到主解决感。
因此小调歌曲结尾经常使用V7-i。

# 次属和弦
次属和弦是临时把某个非主和弦当作主和弦，为它加入属和弦。
例如C大调中：
D7-G-C
其中D7不是C大调自然和弦，而是G的属七和弦，因此记为V/V。
A7-Dm可理解为V/ii。
E7-Am可理解为V/vi。
次属和弦能够增加和声推动力和色彩。

# 借用和弦
借用和弦通常从平行大小调中借用。
例如C大调中可以借用C小调的Fm。
C-F-Fm-C是一种常见的抒情进行。
大调中的bVI、bVII、iv等借用和弦能够增加忧郁、怀旧或戏剧性色彩。
流行歌曲中常见：
C - Em - F - Fm
C - G - Bb - F
C - Ab - Bb - C。

# 和弦替代
相同功能的和弦可以互相替代。
主功能中I、vi、iii可以在一定程度上互换。
下属功能中ii和IV可以互换。
属功能中V和vii°可以互换。
例如C-G-Am-F可以替换为：
C-Em-Am-F
Am-G-F-G
C-Dm-G-C。
替代和弦能够保持功能方向同时增加变化。

# 三全音替代
爵士音乐中，属七和弦可以用相距三全音的另一个属七和弦替代。
例如G7可以用Db7替代。
原进行：
Dm7-G7-Cmaj7
可以改成：
Dm7-Db7-Cmaj7。
这种进行具有半音下行的低音线，爵士感很强。

# 挂留和弦
Sus2和弦用二度音代替三音。
例如Csus2：C D G。
Sus4和弦用四度音代替三音。
例如Csus4：C F G。
挂留和弦没有明确大小调属性，具有开放、悬浮、未解决感。
常见解决：
Gsus4-G
Dsus4-D。
适合流行、摇滚、民谣和氛围音乐。

# Add和弦
add9是在普通三和弦基础上增加九度音。
例如Cadd9：C E G D。
add9不像九和弦那样必须包含七音，因此声音更干净。
Gadd9、Cadd9、Dadd9在流行和民谣中非常常见。
add9可以让简单和弦更现代、更通透。

# Power Chord强力和弦
Power Chord通常只包含根音与五度，没有三音。
例如C5：C G。
由于没有三音，因此没有明显大调或小调属性。
常用于摇滚、朋克、金属、电吉他编曲。
强力和弦常搭配失真效果和八度叠加。

# Slash Chord分数和弦
Slash Chord表示指定低音。
例如C/E表示C和弦，但最低音为E。
G/B表示G和弦，但最低音为B。
分数和弦常用于制造平滑的低音线。
例如：
C - G/B - Am - Am/G - F
可以形成C-B-A-G-F的连续低音。

# Voice Leading声部连接
声部连接指不同和弦之间各个音尽量以最短距离移动。
良好的声部连接能够让和弦变化更加自然。
例如：
C：C E G
Am：A C E
两个和弦有C、E两个共同音，因此连接非常自然。
编配时应优先保留共同音，其他音尽量级进移动。
钢琴和弦不需要每次都回到根音位置。

# Open Voicing开放排列
开放排列是把和弦音分散在更宽的音域。
例如C和弦可以排列为：
C2-G2-E3-G3-C4。
相比C3-E3-G3，声音更宽、更有空间感。
适合钢琴伴奏、电影音乐、抒情流行。
低音区避免放置过密三和弦，否则容易浑浊。

# Close Voicing密集排列
密集排列指和弦音集中在一个八度附近。
例如C-E-G-B。
适合爵士钢琴、电钢琴、合成器Pad。
在中高音区使用效果较好。
低音区过度密集会导致频率冲突。

# Drop 2 Voicing
Drop 2常用于爵士和吉他和声。
方法是把四声部和弦中的第二高音降低一个八度。
例如Cmaj7密集排列：
C E G B
经过Drop 2可以形成：
G C E B。
这种排列声音更开放，适合吉他、钢琴和爵士编曲。

# 延伸和弦
九和弦：七和弦基础上加入九度音。
Cmaj9：C E G B D。
G9：G B D F A。
Am9：A C E G B。

十一和弦：继续加入十一度音。
Dm11：D F A C E G。

十三和弦：加入十三度音。
G13通常包含G B F E，也可以省略部分音。
延伸和弦常用于爵士、Neo Soul、R&B、城市流行。

# R&B和弦技巧
R&B常使用maj7、m7、m9、maj9、add9等和弦。
常见进行：
Cmaj7 - Am7 - Dm7 - G7
Am9 - Dm9 - G13 - Cmaj9
Fmaj7 - Em7 - Dm7 - G7。
R&B编曲强调和弦转位和顺滑的声部连接。
和弦不要频繁大跨度跳动。
电钢琴Rhodes是常见主和声乐器。

# Neo Soul和声特点
Neo Soul大量使用七和弦、九和弦、十一和弦和复杂转位。
和弦节奏常常略微延后拍点，形成松弛感。
常见特点：
低音线独立移动
和弦顶音形成旋律
大量半音连接
sus、add9、maj9频繁使用。
鼓组通常具有轻微Swing和后拍感。

# 调式基础
Ionian伊奥尼亚调式：等同自然大调，明亮稳定。
Dorian多利亚调式：小调色彩，但第6级升高，忧郁中带明亮感。
Phrygian弗里几亚调式：小调色彩，第2级降低，神秘、异域。
Lydian利底亚调式：大调色彩，第4级升高，梦幻、漂浮。
Mixolydian混合利底亚调式：大调色彩，第7级降低，摇滚、布鲁斯常见。
Aeolian爱奥尼亚调式：自然小调。
Locrian洛克里亚调式：第2、5级降低，非常不稳定。

# 多利亚调式
D Dorian：
D E F G A B C。
相比D自然小调，B音升高。
常用于爵士、Funk、Soul、电影音乐。
听感既有小调的忧郁，又没有自然小调那么沉重。
适合“克制但有希望”的情绪。

# 混合利底亚调式
G Mixolydian：
G A B C D E F。
相比G大调，F#降低为F。
常见于摇滚、布鲁斯、乡村。
常见进行：
G-F-C-G。
具有开放、自由、不完全解决的感觉。

# 利底亚调式
C Lydian：
C D E F# G A B。
升高的第四级带来梦幻和漂浮感。
适合电影、游戏、奇幻、未来感音乐。
常见和声可以使用：
Cmaj7 - D - Cmaj7。

# 蓝调音阶
小调蓝调音阶结构：
1-b3-4-b5-5-b7。
A蓝调音阶：
A C D Eb E G。
适合蓝调、摇滚、爵士、Soul。
b5被称为蓝调音，能够制造独特张力。

# 大调五声音阶
大调五声音阶结构：
1-2-3-5-6。
C大调五声音阶：
C D E G A。
没有半音冲突，旋律自然、明亮。
适合流行、民谣、乡村、儿童音乐。

# 小调五声音阶
小调五声音阶结构：
1-b3-4-5-b7。
A小调五声音阶：
A C D E G。
常用于摇滚、蓝调、流行、电吉他Solo。
旋律容易生成且不容易产生明显错音。

# 旋律音域控制
流行人声旋律通常控制在1个到1.5个八度以内。
主歌音域可以较窄，保持叙事感。
副歌可适当升高整体音区并扩大音域。
旋律最高音通常安排在副歌或情绪关键词。
连续大跳容易难唱，应与级进结合。
旋律大跳后通常使用反向级进进行平衡。

# 旋律动机
动机是旋律中最小的可识别单位。
通常由2-5个音组成。
好的旋律会重复核心动机，再进行节奏或音高变化。
例如：
C-D-E
可以变化为：
D-E-F
C-D-G
C-D-E-E。
重复建立记忆点，变化保持新鲜感。

# 旋律重复原则
副歌旋律通常比主歌重复更多。
主歌适合较多旋律变化以配合歌词叙事。
副歌应保留明显的重复句式。
同一段副歌第二次出现时可以加入八度、和声或尾音变化。

# 旋律与和弦关系
强拍上的旋律音优先使用当前和弦内音。
弱拍可以使用经过音、邻音等非和弦音。
和弦C下稳定音为C、E、G。
和弦Am下稳定音为A、C、E。
非和弦音适合放在弱拍并快速解决到和弦音。
长音最好落在和弦音上。

# 经过音
经过音用于连接两个和弦音。
例如C和弦中E和G之间可以加入F：
E-F-G。
F不是C和弦构成音，但作为经过音可以自然出现。
经过音通常出现在弱拍。

# 邻音
邻音从一个和弦音出发，上行或下行一级，再回到原音。
例如：
E-F-E
G-A-G。
邻音能够让旋律更有装饰性，同时保持稳定。

# 倚音
倚音通常出现在强拍上，是一个非和弦音，然后解决到和弦音。
例如在C和弦上：
F-E。
F制造短暂紧张，随后解决到E。
倚音适合制造情感张力。

# 先现音
先现音是在和弦变化前，提前出现下一个和弦的音。
例如C→G时，可以在C和弦最后半拍提前出现B或D。
能够让和弦连接更加顺畅。

# Hook写作
Hook是歌曲最容易被记住的部分。
可以来自：
旋律Hook
歌词Hook
节奏Hook
和弦Hook
音色Hook。
流行歌曲通常会在前30-60秒内出现一次明显Hook。
副歌第一句经常承担主要Hook。
Hook应简短、重复、有明显节奏特征。

# 主歌写作
主歌负责推进故事和信息。
旋律通常比副歌低。
音符密度可以较高，但音域较窄。
和弦可以保持稳定或重复。
歌词应提供人物、地点、事件或场景。

# 预副歌写作
预副歌用于从主歌过渡到副歌。
常见方法：
旋律逐渐上行
和弦节奏加快
加入属功能和弦
鼓组逐渐增强
减少歌词重复。
预副歌结尾应产生明显“要进入副歌”的期待。

# 副歌写作
副歌应是歌曲情绪和记忆点的中心。
常见特点：
音域升高
旋律重复
歌词简洁
节奏更稳定
和弦更开放
编曲更厚。
副歌第一句通常最好直接出现歌曲核心主题。

# Bridge桥段写作
Bridge通常只出现一次。
作用是打破主歌和副歌的重复。
可以改变：
和弦
调性
旋律音区
节奏
歌词视角
乐器配置。
Bridge结束后通常回到最终副歌。

# Intro前奏设计
流行歌曲前奏通常为2、4或8小节。
可以使用：
副歌Hook的简化版本
主和弦进行
特征音色
吉他Riff
钢琴动机。
前奏不宜过长，否则影响进入正文的速度。

# Outro尾奏设计
尾奏可以采用：
重复副歌最后一句
重复核心和弦
渐弱Fade Out
全乐队突然结束
保留单一乐器收尾。
情歌常使用渐弱或延长主和弦。
摇滚常使用明确结束。

# 4/4常见鼓点
最基础流行鼓点：
底鼓：第1拍、第3拍。
军鼓：第2拍、第4拍。
踩镲：每个八分音符。
可以形成稳定的流行律动。
副歌可以增加开放踩镲、Crash和更多底鼓。

# Rock鼓点
摇滚常见：
军鼓固定在2、4拍。
底鼓增加切分和连续击打。
踩镲或Ride保持八分音符。
副歌第一拍通常加入Crash。
Fill常出现在每4或8小节结尾。

# R&B鼓点
R&B鼓点通常比普通流行更松弛。
军鼓或Clap强调2、4拍。
底鼓可以使用切分节奏。
踩镲不一定完全量化，可以略微提前或延后。
部分音符力度降低形成Ghost Note。

# Trap鼓点
Trap常用808低音鼓。
军鼓或Clap通常位于半拍感觉中的第3拍。
Hi-hat常出现16分音符滚奏和32分音符Roll。
808低音可加入滑音。
整体节奏强调空隙和低频。

# Lo-fi鼓点
Lo-fi鼓点通常有轻微Swing。
底鼓和军鼓力度较弱。
鼓点可以略微偏离网格，避免机械感。
常使用噪声、磁带感、黑胶噪点。
BPM常在70-90。

# Swing
Swing会改变连续八分音符的时值比例。
直八分音符为1:1。
Swing可以接近2:1。
Jazz、Shuffle、Neo Soul常使用Swing。
Swing值过大容易显得拖沓，应根据风格调整。

# Humanize人性化
完全量化的MIDI容易产生机械感。
Humanize可以随机调整：
音符起始时间
Velocity
音符长度。
时间偏移通常保持很小，例如±5到20毫秒。
力度可以在基础值上下轻微波动。
鼓和吉他的Humanize尤其重要。

# Velocity设计
同一乐器的所有音符不应使用完全相同Velocity。
钢琴弱奏可使用45-70。
普通演奏可使用65-95。
强调音可使用90-115。
连续音符可以产生轻微力度起伏。
过高Velocity会让音色过于生硬。

# 钢琴编曲
钢琴左手通常负责低音或根音。
右手负责和弦与旋律。
抒情歌可使用分解和弦。
副歌可以改为完整和弦增加厚度。
低音区避免连续密集三和弦。
右手可使用转位保持声部连接。

# 钢琴分解和弦
常见4/4分解方式：
1-5-3-5
1-5-8-5
1-3-5-8。
慢歌可使用八分音符连续分解。
主歌用较疏的分解，副歌增加音符密度。
高音区可以加入重复顶音。

# 吉他扫弦
4/4基础扫弦可以使用：
下 下上 上下上。
轻柔民谣可以减少扫弦次数。
副歌可以增加连续八分音符扫弦。
向下扫弦通常力度更强，向上扫弦更轻。
Velocity应体现这种差异。

# 吉他分解
常见吉他分解模式：
Bass-3-2-1-2-3。
根音可以随和弦变化。
主歌使用分解能够保留歌词空间。
副歌切换扫弦可产生明显动态对比。

# 贝斯编写
贝斯首先需要跟随和弦根音。
强拍优先使用根音。
可以加入五度、八度和经过音。
流行贝斯通常强调1拍和3拍。
Funk和R&B贝斯可以加入更多切分。
贝斯应与底鼓形成节奏配合。

# Walking Bass
爵士Walking Bass通常每拍一个音。
主要使用：
根音
三音
五音
七音
半音经过音。
目标是在下一小节第一拍自然落到新和弦根音或和弦音。

# 弦乐编曲
弦乐可以承担：
长音Pad
旋律
对旋律
节奏型和声。
主歌可以只用低音弦乐或长音。
副歌增加小提琴高音线条。
避免所有弦乐声部一直齐奏相同旋律。

# Pad编曲
Pad主要负责填充和声空间。
Attack通常较慢。
Release较长。
适合副歌、Bridge、氛围音乐。
Pad不需要频繁换音，可持续整个和弦时值。
低频应适当减少，避免和贝斯冲突。

# Synth Lead
Synth Lead通常承担Hook或Solo。
旋律不宜与人声同时过于复杂。
前奏或间奏可以使用Lead展示歌曲主题。
人声进入后Lead可以改为短句回应。

# 配器层次
一个完整流行编曲可分为：
低频：Kick、Bass。
中低频：钢琴左手、吉他低音。
中频：钢琴、吉他、电钢琴。
中高频：人声、弦乐。
高频：Hi-hat、Shaker、亮色Synth。
不同层应避免长期占据相同频率和节奏位置。

# 主歌与副歌动态
主歌通常减少乐器数量。
副歌增加：
鼓
贝斯
高音和声
Pad
弦乐
Crash。
即使和弦相同，通过编曲层次变化也能产生情绪提升。

# Build Up
Build Up用于进入副歌或高潮。
常见方法：
鼓点逐渐密集
Snare Roll
和弦持续音
滤波逐渐打开
音高上升
白噪声Rise。
Build Up最后可以短暂停顿，再进入高潮。

# Drop
电子音乐中的Drop是高潮段落。
通常在Build Up之后出现。
特点：
低频突然增强
鼓组完整进入
主Hook出现
音色更厚
节奏更强。
Drop前短暂停顿可以增加冲击力。

# 音乐密度
音乐密度指单位时间内出现的音符数量和乐器数量。
低密度适合平静、悲伤、孤独。
高密度适合兴奋、高潮、舞曲。
歌曲应在不同段落改变密度，避免从头到尾一样。

# 节奏密度
主歌可以使用较少鼓点和较长音符。
预副歌逐渐增加八分音符或十六分音符。
副歌使用更密集节奏。
Bridge可以再次降低密度形成反差。

# 情绪变化设计
歌曲不应只维持一种情绪强度。
可以设计：
Intro 2/5
Verse 2/5
Pre-Chorus 3/5
Chorus 4/5
Verse 2 3/5
Bridge 3/5
Final Chorus 5/5
Outro 1/5。
这种能量曲线适合流行歌曲。

# 流行歌曲能量曲线
Intro：低能量。
Verse：稳定叙事。
Pre-Chorus：逐渐提升。
Chorus：第一次高潮。
Verse 2：比Verse 1略丰富。
Bridge：形成反差。
Final Chorus：全曲最高能量。
Outro：逐渐结束。

# 民谣歌曲能量曲线
Intro：吉他独奏或分解。
Verse 1：单吉他+人声。
Verse 2：加入轻打击乐。
Chorus：扫弦+贝斯。
Bridge：降低动态。
Final Chorus：加入和声或弦乐。
Outro：回到单吉他。

# R&B歌曲能量曲线
Intro：Rhodes或Pad。
Verse：稀疏鼓点+Bass。
Pre-Chorus：增加和弦延伸。
Chorus：加入和声与更多节奏层。
Bridge：减少鼓点突出人声。
Final Chorus：加入Ad-lib与高声部和声。

# 摇滚歌曲能量曲线
Intro：吉他Riff。
Verse：节奏吉他较弱。
Pre-Chorus：鼓点增强。
Chorus：失真吉他+Crash。
Verse 2：增加第二把吉他。
Solo或Bridge：吉他独奏。
Final Chorus：全乐队最高动态。

# 歌词字数与旋律
一句歌词字数越多，通常需要更密集的节奏。
抒情慢歌每小节歌词字数不宜过多。
重要词可以使用长音。
副歌歌词应比主歌更简洁。
重复关键词有利于记忆。

# 中文歌词与旋律
中文歌词以单音节汉字为主。
通常一个汉字对应一个主要音符。
虚词可以放在弱拍或短音。
关键词适合放在强拍、高音或长音。
连续多个复杂跳进容易影响中文咬字清晰度。

# 押韵设计
主歌可以使用ABAB或AABB。
副歌建议使用更明显的统一韵脚。
同一段落的最后一个字尽量保持相似韵母。
避免为了押韵使用不自然表达。
押韵应服务于语义和情绪。

# 歌词意象
悲伤可以使用：
雨、夜、空房间、车站、旧照片、背影。
温暖可以使用：
阳光、早餐、窗台、风、拥抱、灯光。
青春可以使用：
操场、校服、单车、夏天、蝉鸣。
城市可以使用：
地铁、霓虹灯、红绿灯、高楼、出租车。
具体意象通常比“我很难过”更有画面感。

# AI生成歌词规则
避免一整首歌词重复相同句式。
主歌应推进内容。
副歌应总结核心情绪。
Bridge应加入新的角度。
每段歌词长度应相对均衡。
歌曲标题或核心关键词建议在副歌出现。

# AI生成和弦规则
首先根据风格和情绪选择调式。
根据调式选择候选和弦。
基础流行优先使用I、IV、V、vi。
悲伤歌曲增加vi、ii、iv等。
R&B增加maj7、m7、m9、9。
爵士优先ii-V-I。
摇滚可以使用I-bVII-IV和Power Chord。
每个段落不一定使用完全相同的和弦进行。

# AI生成BPM规则
悲伤抒情：65-85 BPM。
温柔流行：80-100 BPM。
普通流行：95-120 BPM。
欢快流行：115-135 BPM。
摇滚：120-160 BPM。
R&B：70-100 BPM。
Lo-fi：70-90 BPM。
House：120-130 BPM。
Techno：130-150 BPM。
朋克：160-220 BPM。

# AI生成Key规则
明亮、轻快优先考虑C、G、D大调。
柔和浪漫优先F、Bb大调。
忧郁优先A、E、D小调。
悲壮优先C、D小调。
民谣优先G、C、D大调。
吉他歌曲优先使用开放和弦友好的调，例如G、C、D、A、E。
如果使用Capo，可以保持简单指法同时改变实际调高。

# 吉他Capo规则
Capo用于整体升高音高，同时保持开放和弦指法。
例如实际调为A大调，可以Capo 2使用G调指法。
实际B大调可以Capo 2使用A调指法。
Capo适合民谣和弹唱。
Capo越高，吉他音色通常越明亮。
通常0-5品最常见。

# MIDI音轨设计
标准歌曲MIDI可以拆分为：
Track 1 Melody
Track 2 Chords
Track 3 Bass
Track 4 Drums
Track 5 Strings或Pad。
不同音轨使用独立Channel。
鼓通常使用Channel 10。
每个音轨应设置合适Program Change。

# MIDI旋律规则
旋律轨不应持续与和弦完全重叠。
主歌旋律可以较低。
副歌整体提高音区。
Velocity随段落能量变化。
长音应延长Note Off时间。
同一音连续重复时可改变Velocity避免机械感。

# MIDI和弦规则
和弦可以使用整拍、二分音符、八分音符或分解节奏。
主歌使用较疏的和弦节奏。
副歌增加和弦密度。
钢琴优先使用转位。
吉他应模拟扫弦，让不同琴弦音符略微错开，而不是同时触发。

# MIDI吉他扫弦模拟
真实吉他扫弦中，六根弦不会完全同时发声。
向下扫弦可以让低音弦先发声，高音弦延迟数毫秒。
向上扫弦方向相反。
每根弦Velocity略有不同。
这种微小时差可以减少“键盘和弦感”。

# MIDI鼓规则
Kick通常使用36。
Snare通常使用38。
Closed Hi-hat通常使用42。
Open Hi-hat通常使用46。
Crash Cymbal通常使用49。
Ride Cymbal通常使用51。
GM鼓组位于Channel 10。
不同鼓音Velocity应有变化。

# MIDI贝斯规则
贝斯常使用E1-C4附近音区。
根音通常放在强拍。
不要让Bass和钢琴左手长期完全重复。
副歌可以增加八度跳进。
R&B可以增加切分和经过音。

# MIDI段落差异
Verse：
鼓简单
Bass稀疏
伴奏较轻。

Pre-Chorus：
增加鼓点
和弦节奏变密
Bass开始上行或增强。

Chorus：
鼓组完整
Bass更活跃
和弦更密
增加高音层。

Bridge：
改变节奏或配器。

Final Chorus：
增加Crash
增加八度
增加和声层
整体Velocity提高。

# MIDI结束设计
歌曲结束不应突然在任意位置停止。
可以选择：
主和弦长音
和弦Arpeggio结束
全乐器同时结束
逐渐减弱Velocity。
最后一个和弦通常持续2-4拍。

# 常见生成错误
和弦与调式不一致会造成明显违和。
所有段落使用完全相同编曲会显得机械。
所有音符Velocity一致会像电脑演奏。
吉他和弦完全同时发音会像钢琴。
Bass只重复根音可能显得单调。
旋律频繁随机跳进会缺乏可唱性。
副歌如果没有音区或密度提升，会缺少高潮。

# AI音乐生成质量检查
生成完成后可以检查：
调式是否统一
BPM是否符合风格
和弦是否合理
旋律是否可唱
副歌是否有明显Hook
主歌与副歌是否有动态区别
低音是否跟随和声
鼓点是否符合风格
歌词段落是否完整
MIDI是否存在明显越界音高。

# 音乐生成一致性指标
可以从以下维度评估：
风格匹配度
情绪匹配度
和弦合理性
旋律可唱性
曲式完整性
编曲层次
乐器合理性
节奏稳定性
歌词与旋律适配度。
可以使用人工评分1-5分进行评价。

# RAG音乐知识检索建议
用户输入中包含“悲伤”“失恋”等情绪词时，应优先检索情绪与调式、BPM、和弦相关知识。
出现“民谣”时，应检索民谣BPM、吉他和弦、扫弦、Capo相关内容。
出现“R&B”时，应检索七和弦、九和弦、Rhodes、切分节奏相关知识。
出现“摇滚”时，应检索Power Chord、鼓组、失真吉他、BPM相关知识。
出现“爵士”时，应检索ii-V-I、七和弦、延伸和弦、Walking Bass相关内容。
不同风格只需要召回与当前生成任务高度相关的知识，不需要把整个知识库都加入Prompt。

# RAG检索优先级
用户明确指定的信息优先级最高：
用户指定BPM > 知识库推荐BPM。
用户指定Key > 系统自动Key。
用户指定乐器 > 风格默认乐器。
用户指定情绪 > 风格默认情绪。
RAG知识应作为生成建议，而不是覆盖用户明确要求。

# RAG生成约束
检索结果主要用于帮助模型选择：
BPM
Key
Chord Progression
Song Structure
Instrument
Arrangement Style。
不要让检索内容直接替代用户需求。
当知识库不同片段发生冲突时，优先选择与当前Genre和Mood更匹配的片段。

# Prompt上下文控制
一次检索不应放入过多知识。
通常选择3-5个高相关片段。
优先保留：
风格规则
和弦规则
BPM规则
结构规则
编曲规则。
基础乐理定义在实际歌曲生成时优先级较低。

# 音乐知识库切块建议
优先按标题和主题切块。
不要把“R&B规则”和“摇滚规则”放在同一Chunk。
一个Chunk围绕一个明确问题，例如：
R&B和弦
民谣BPM
摇滚鼓点
悲伤情绪参数。
每个Chunk保留标题，有利于向量检索理解语义。
相邻内容可以保留少量Overlap，避免上下文断裂。

# 知识库Metadata建议
每个知识块可以保存：
category
genre
mood
instrument
topic
source。
例如：
category=genre
genre=R&B
topic=chord
instrument=piano。
Metadata可以帮助后续做条件过滤，提高检索准确度。

# 风格组合规则
用户可能同时提出多个风格。
例如“R&B民谣”：
保留民谣的木吉他和叙事感，
加入R&B的七和弦、切分和Rhodes元素。
“电子摇滚”：
保留摇滚的电吉他与鼓组，
加入电子Synth与稳定节拍。
混合风格应确定一个主风格、一个辅助风格，避免平均混合导致风格不明显。

# 情绪组合规则
“悲伤但有希望”：
可以使用小调主歌、大调色彩副歌。
BPM保持中慢速。
副歌旋律上行。
“温柔但孤独”：
使用maj7、add9等柔和和弦，
低动态，
中慢BPM。
“压抑到爆发”：
主歌低音区、低密度，
副歌提高音区和Velocity，并增加鼓与失真吉他。

# 音乐生成产品规则
用户没有专业音乐知识时，应自动补全合理的BPM、Key和Chord。
用户有明确音乐参数时，应尊重用户参数。
生成结果应同时提供可理解的自然语言解释。
例如：
“选择A小调和78 BPM，是因为更适合忧郁慢歌。”
产品应避免只输出专业术语而不给用户解释。

# 弹唱辅助
对于吉他歌曲，应显示：
和弦名称
Capo
常用指法
歌词对应和弦位置。
对于钢琴歌曲，应显示：
和弦构成音
琴键位置
和弦转位建议。
对于完全没有乐理基础的用户，可以额外提供简单解释，例如“这一句在G和弦开始唱”。

# 人声导唱功能
人声导唱的主要目标不是代替专业歌手，而是帮助用户理解旋律应该如何演唱。
导唱需要考虑：
歌词音节与音符对齐
旋律音高
节奏
换气位置
长音
副歌高潮。
第一版可以优先保证音高和节奏正确，再逐步优化音色和情感表达。

# 人声导唱产品价值
弹唱谱告诉用户“弹什么”。
人声导唱告诉用户“怎么唱”。
伴奏告诉用户“整体音乐是什么感觉”。
三者结合能够降低非专业用户的音乐创作门槛。
